# Slide Grabber
Открываешь видео с пары → обводишь рамкой презентацию → «Сделать снимки слайдов».
На рабочем столе появится папка `Слайды - <имя видео>` с уникальными слайдами (только с текстом, без повторов и похожих).

Сборка `.exe`: вкладка **Actions** → последний запуск **Build exe** → артефакт `SlideGrabber`.
Запуск из исходников: `pip install -r requirements.txt && python app.py`
